Accepted formats

Foo.jpg · File:Foo.jpg · commons.wikimedia.org/wiki/File:Foo.jpg · https://upload.wikimedia.org/wikipedia/commons/0/06/Foo.jpg · …/thumb/0/06/Foo.jpg/640px-Foo.jpg · Special:FilePath/Foo.jpg · …/w/index.php?title=File:Foo.jpg · [[File:Foo.jpg|thumb|caption]]

Case, underscores, %20 encoding, bullets/numbering and quotes are all tolerated; duplicates are merged. A comma or semicolon only separates two entries when another entry follows it (a File: prefix, a URL, [[), so file names that contain a comma — …(In die Sonne schauen, Cannes 2025).jpg — stay intact, and Foo.jpg, Bar.jpg still splits. Non-photo media (SVG, PDF, video keyframes) resolve too — Commons renders a raster thumbnail. Category listings are not supported yet (paste the file names instead). For the exact request sent to Clef and what every answer means, press About (top right) — including the verbatim prompt and the quality legend.
